# IPL Winner Prediction App

This project predicts IPL match winner using Machine Learning.

## Technologies
- Python
- Scikit-learn
- Pandas
- Git & GitHub

## Files
- app.py → main application
- model.pkl → trained model
- encoders → preprocessing files
## How to Run
1. Clone the repo
2. Install requirements
3. Run app.py
